## Main Features
<a id="main-features"></a>

### Core Functionality
- **Subtitle Extraction** — Quickly extract subtitles from VOB files on your DVD. Simply select the desired subtitle chain and press 'Start' to initiate the extraction process.
- **Optical Character Recognition (OCR)** — SubRip uses advanced OCR technology to convert graphical subtitle formats into readable SRT files, enhancing accuracy and usability.
- **IFO and VOB File Support** — Load the DVD's file structure using IFO files for a more effective extraction process, particularly useful for unprotected discs.
- **User-Friendly Interface** — Designed with ease of use in mind, SubRip provides a straightforward layout that simplifies subtitle extraction for users of all experience levels.
- **Batch Processing Capabilities** — Extract multiple subtitle streams simultaneously, saving you time and effort when working with larger projects.
